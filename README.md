# Student Result Management System

A MERN-stack web application for managing academic results, with Admin, Teacher, and Student roles.

> **Status:** early development. Nothing in this repository is production-ready yet.

## Planned stack

- Frontend: React, Vite, JavaScript, Tailwind CSS (planned)
- Backend: Node.js, Express.js (planned)
- Database: MongoDB Atlas with Mongoose (planned)
- Testing: Vitest or Jest, Supertest, Postman (planned)

## Repository layout

- `server/` : Express API (folder structure created, no code yet)
- `client/` : React app (to be created in a later phase)

## Data

All student records used in this project are fictional.

## Development environment

Developed with Node.js v24.15.0 and npm 11.12.1.

Full setup instructions, architecture notes, and API documentation will be added as the project is built.
